# PACER 楼梯课程训练计划（2026-11-08）

> 本文件只记录课程训练方案，不代表代码已经实现。  
> 当前核心问题不是 L 形、宽度或训练时长，而是：**训练分布中上楼梯样本太少，且第一级 riser 的摆动脚净空/落脚没有被有效约束。**

---

## 1. 为什么需要课程

现有实验显示：

- 纯增加训练量到 49,700 epoch，训练 reward 从 59 上升到约 72；
- 固定楼梯评测仍在 1.0–1.2 秒、1–2 级左右失败；
- 训练场景统计中：
  - 平地约 95.6%；
  - 上台阶仅约 1.57%；
  - 43/64 个 episode 一步都没上台阶；
- 但训练场景中最好 run 能上 20 级。

结论：

> **模型不是完全不会上楼，而是训练分布对上楼覆盖太少，且进入第一级的速度/距离没有被系统随机化。**

因此课程的目标不是“只练简单楼梯”，而是：

1. 先让上楼样本成为主要分布；
2. 先学会第一级抬脚；
3. 再逐步扩大高度、踏面、宽度；
4. 始终保留简单样本，避免遗忘和退化；
5. 每阶段用同一套评测协议验证。

## 3. 课程设计原则

### 3.1 重叠式课程

不是：

```text
Stage 1 只采样 0.08–0.11
Stage 2 只采样 0.08–0.14
```

而是：

```text
Stage 2 = 80% 新范围 + 20% Stage 1 简单样本
Stage 3 = 70% 新范围 + 30% 简单样本
Stage 4 = 20% 简单 + 50% 中等 + 30% 困难
```

### 3.2 连续随机

所有参数必须连续采样：

```text
riser
tread
width
start distance
approach speed
step count
```

不能只训练固定几块 mesh，否则会记住楼梯。

### 3.3 训练与评测一致

训练和评测都要记录：

```text
路径进度百分比
到达第几级
首次真实失败
爬升高度
水平位移
```

不能只看 reward 或存活帧数。

### 3.4 不先做 L 形

当前先做直楼梯。

L 形、90° 拐角、平台转向后续由上层路径规划处理，不纳入本轮课程。

## 5. 每阶段训练分布

### Stage 1：基本抬脚

目标：

```text
先学会迈上第一级，不要求速度
```

参数：

```text
riser: 0.08–0.11
tread: 0.36–0.42
width: 2.4–3.0
步骤: 5–7
平台: 2.0–3.0 m
```

建议：

```text
楼梯样本占比: 100%
起始距离: 0.4–0.8 m
进入速度: 0.5–1.5 m/s
```

通过标准：

```text
直楼梯 0.10 m
宽 2.8 m
3 seeds 都能稳定通过第一级
```

如果 0.08 m 都上不去：

```text
停止课程
先查抬脚奖励/初始姿态/评测起点
```

### Stage 2：增加高度

```text
riser: 0.08–0.14
tread: 0.32–0.40
width: 2.0–3.0
steps: 6–8
```

训练分布：

```text
80% 当前范围
20% Stage 1 简单样本
```

通过标准：

```text
0.12 m / 宽 2.4 m
多 seed 稳定通过
```

### Stage 3：接近真实尺寸

```text
riser: 0.10–0.17
tread: 0.28–0.36
width: 1.6–2.8
steps: 8–10
```

训练分布：

```text
70% 当前范围
30% Stage 1–2 简单样本
```

通过标准：

```text
0.15 m / 宽 1.8 m
能连续上下
```

### Stage 4：完整直楼梯分布

```text
riser: 0.08–0.22
tread: 0.24–0.38
width: 1.2–3.0
steps: 8–12
```

训练分布：

```text
20% 简单: 0.08–0.12 / 2.4–3.0
50% 中等: 0.12–0.17 / 1.6–2.8
30% 困难: 0.17–0.22 / 1.2–2.0
```

通过标准：

```text
0.15/0.30 宽 2.8 与 1.2
多 seed 都能通过第一级并走完
```

## 6. 评测协议

每个阶段结束至少跑：

```text
width: 2.8 / 1.8 / 1.2
riser: 0.10 / 0.12 / 0.15 / 0.18
seed: 0 / 1 / 2
```

指标：

```text
是否通过第一级
首次真实失败帧
到达第几级
路径进度百分比
最大爬升高度
水平位移
```

禁止只用：

```text
reward
存活帧数
修改终止规则后的结果
```

正式对比必须使用同一套终止规则和 episode 长度。

## 7. 实现顺序

1. 在 `humanoid_pedestrain_terrain.py` 增加直楼梯生成；
2. 增加 `stair_width_min/max`；
3. 每块 tile 随机 riser/tread/width；
4. 创建 stage 1–4 配置；
5. 创建课程启动脚本；
6. 本地自检；
7. 本地 git commit；
8. 同步到 3090；
9. 先在低台阶验证，再逐阶段推进。

---

## 8. 风险

- 直楼梯和当前 pyramid 地形差异大，需要重新适应；
- 2048 个独立 mesh 会显存不足，优先单张 atlas 或小 tile；
- 课程可能只改善低台阶，0.15+ 仍失败；
- 如果 0.08 m 都上不去，说明不是课程问题，而是抬脚/奖励问题；
- 评测协议不改，reward 再高也不能证明能力。
